# Overlap

A speculative brand website for **Overlap**, a private AI chat with a team map.
Thesis project by Feifey · MFA Interaction Design, School of Visual Arts.

> Some things should stay.

## Pages

- `index.html`: Home
- `product.html`, `services.html`, `integrations.html`
- `labs/`: four Lab pages (deliberately non-commercial)
- `community.html`, `privacy.html`, `about.html`

Plain HTML and CSS. No build step. Colors live at the top of `assets/style.css`.

## Live site

Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
